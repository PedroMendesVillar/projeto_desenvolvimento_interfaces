## 📜 Sobre o Projeto

Este projeto é uma aplicação web interativa dedicada ao universo de **Elden Ring**, criada tanto por admiração ao trabalho da *FromSoftware* quanto para servir como um **laboratório prático de desenvolvimento frontend**.

O objetivo principal é construir um portal completo contendo informações sobre chefes, *lore*, itens e mapas, servindo como portfólio prático e registro visual do meu crescimento técnico.

## 🔄 Por que Múltiplas Versões?

Assim como a jornada de um Maculado exige constante aperfeiçoamento, este repositório foi estruturado para documentar o meu **progresso técnico ao longo do tempo**.

Em vez de apenas sobrescrever o código a cada atualização, o projeto mantém um histórico de versões estruturado. Isso permite:

1. **Visualizar a Evolução Prática:** Acompanhar a transição de um site estático básico para uma aplicação rica e moderna.
2. **Comparar Ferramentas e Paradigmas:** Testar diferentes tecnologias, bibliotecas de estilização e estruturas de projeto.
3. **Documentar Aprendizados:** Registrar conquistas no domínio de acessibilidade, responsividade, consumo de APIs e boas práticas.
